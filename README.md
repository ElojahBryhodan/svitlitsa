# Світлиця — лендінг

Кав’ярня і коворкінг у Черкасах, які створює громадська організація «Світлиця».

**Живий перегляд:** <https://elojahbryhodan.github.io/svitlitsa/>

---

## Що це

Перший варіант головної сторінки. Одна HTML-сторінка без збірки: відкриваєш `index.html` — працює.

- **Контент** відтворено дослівно з джерела ГО. Жодного рядка не переписано, не скорочено й не додано.
- **Естетика** — за дизайн-системою «Світлиця» v2.0: типографічна шкала, ритм відступів, посекційна карта.
- **Палітра** — фірмова родина логотипа (тепла маруна + пісок), полегшена: темні заливки підняті з L\*17.6 до L\*29, акцент переведено з неонового `#F85830` у теракоту, чистий білий замінено теплою слоновою кісткою. Середній L\* заливкових секцій: 28.0 → 44.5.
- **Дев’ять секцій** із чергуванням тем `dark → light → light → dark → signal → light → light → dark → ink`.

## Структура

```
index.html        вся сторінка: розмітка, CSS і JS інлайном
assets/images/    7 файлів .webp (4 основні + 3 дрібні варіанти)
```

Збірки немає — GitHub Pages віддає `index.html` із кореня гілки `main` як є.

## Локальний запуск

```bash
python3 -m http.server 4173
```

Далі відкрити <http://localhost:4173>.

Можна просто двічі клацнути `index.html` — усе, крім `srcset`, працює і так.

## Технічне

- Анімації на GSAP 3 + ScrollTrigger з CDN. Якщо CDN недоступний, сторінка показує весь вміст без анімацій — контент ніколи не лишається схованим.
- `prefers-reduced-motion` вимикає рух, лишаючи тільки прозорість.
- Перевірено на 390 / 768 / 1280 / 1440 px, горизонтального скролу немає.
- Усі пари текст/тло проходять WCAG. Перевірено не лише за токенами, а й по композиту: скло `backdrop-filter` над реальним кадром hero і градієнтні скрими рахуються з фактичною яскравістю фото (5-й і 95-й перцентилі).
- Шрифти Unbounded (display) і Onest (текст) з Google Fonts — обидва з повним українським набором.

## Відомі відступи від дизайн-системи

Три свідомі рішення, де файл суперечив сам собі або реальним даним:

1. **`signal`-секція — тінт акценту, а не суцільна заливка.** Помаранч на всю висоту секції був головним джерелом зорової ваги. Тло секції — `--c-signal-soft`, заголовки `ink` (10.4). Акцент лишається один на сторінку, просто звучить тихіше. Цифра **4** лишилась `sand`, бо лежить на forest-колі (4.32).
2. **Ланцюжок у розділі «Як твоя чашка допомагає» — вертикальний.** У двоколонковій розкладці на ланку припадає близько 170 px; горизонтальний ряд дав би сім рядків тексту замість трьох.
3. **Затемнення hero посилене знизу.** Заголовок і кнопка стоять унизу кадру, тому градієнт розвернуто — вимога читабельності важливіша.
